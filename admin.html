SETUP REQUIRED

Connect Supabase

This admin panel is built, but it needs your Supabase project URL and anon key before login and uploads can work.

  1. Open config.js in your GitHub repo.
  2. Paste your Supabase project URL and anon/public key.
  3. Run the included supabase/schema.sql in the Supabase SQL editor.
  4. Create your admin account in Supabase Authentication.
